# TJU 高校应用文场景模板集（tju-extension）

> 配合上游核心使用：文种选择与语言规范见上游安装目录的 `SKILL.md`；语言四原则与规范用语见
> 上游 `references/writing-techniques.md`；成文后排版产出交运行环境的文档生成能力（如 academic-office MCP）。
> 结构层次序数沿用公文惯例：一、 → （一） → 1. → （1）。成文日期用阿拉伯数字全称（2026年9月26日）。

通用语言要求（对全部场景生效）：准确、平实、简明、庄重；不用口语、方言、网络语；
数据必须有出处，缺数据处写"待补充"而不是编造；每个文种的结尾语按下表执行。

| 场景 | 结尾语惯例 |
|---|---|
| 请示 | 妥否，请批示。 |
| 报告 | 特此报告。 |
| 通知 | 特此通知。 |
| 申请书/申报书 | 恳请审批。／恳请立项。 |
| 总结/计划/汇报材料/课程报告 | 无固定结尾语，以自然收束或表态句结束 |

## 1. 课程报告

**用途**：本科课程大作业、课程设计、期末报告。

```
[课程名称]课程报告
题目：[具体题目]
学院/专业/班级/学号/姓名/指导教师/日期

摘要（200字左右）+ 关键词（3-5个）

一、引言（问题背景、目的与意义）
二、[理论基础/方案设计/实验方法]（按课程性质替换）
三、[实现过程/实验结果与分析]（图表优先，数据与正文一致）
四、结论（成果、不足与改进方向）
参考文献（GB/T 7714）
```

**要点**：题目写 YAML frontmatter（pandoc Title 样式，不参与章节编号）；章节名不手写编号
（排版管线自动编号）；图表必须被正文引用。
**常见错误**：摘要写成"本文首先……其次……"的目录复述；结论出现正文没有的新论据。

## 2. 科研总结（项目阶段总结 / 结题总结）

**用途**：科研项目中期/阶段总结、结题总结，报导师、学院或项目主管部门。
继承上游"总结"文种三段式（成绩→问题→打算），细化为科研语境：

```
[项目名称]阶段总结（/结题总结）
项目编号、负责人、依托单位、总结期间

一、项目概况与研究目标回顾
二、主要进展与阶段性成果
  （一）研究进展（按任务书条目逐项对照：已完成/进行中/调整说明）
  （二）成果形式（论文/专利/软著/样机/数据集，附清单）
  （三）经费使用情况（预算科目对照，大额支出说明）
三、存在问题与原因分析
四、下一步计划（含时间节点与里程碑）
五、（结题时）成果对照任务书完成情况表

负责人签字 / 日期
```

**要点**：进展必须与任务书/开题报告逐条对照，不写没做过的内容；数据（论文数、
经费执行率）精确到可核对。
**常见错误**：把"计划做"写成"已完成"；问题部分空泛（"经验不足"）而无归因。

## 3. 项目申报（大学生创新训练项目申报书 / 申请书）

**用途**：大创（国家级/市级/校级）、科研立项申请书初稿。

```
[项目类别]项目申报书
项目名称、申请人/团队（学院、学号、专业、年级）、指导教师（职称、研究方向）

一、立项依据
  （一）研究背景与意义（现实需求 + 现状痛点）
  （二）国内外研究现状（有文献支撑，注明出处）
  （三）参考文献
二、项目方案
  （一）研究目标（2-4条，可验收）
  （二）研究内容（与目标一一对应）
  （三）拟解决的关键问题（1-2个）
  （四）研究方法与技术路线（建议附技术路线图）
  （五）可行性分析（团队能力、前期基础、条件保障）
三、创新点（2-3条，说清与现有工作的差异）
四、预期成果（论文/专利/原型/竞赛，标注可考核形式）
五、进度安排（按季度/学期，含中期检查节点）
六、经费预算（按学校科目表：材料费、测试化验加工费、差旅费、资料/印刷费等）
七、基础与保障（前期成果、实验条件）

申请人承诺与签名 / 指导教师意见 / 学院意见（留空）
```

**要点**：目标-内容-成果三者必须闭环可验收；现状综述不得只列文献不评述；
预算合计与分项一致。
**常见错误**：创新点写成"首次提出"却无对照；进度安排没有中期检查节点；
预期成果不可考核（"取得较大进展"）。

## 4. 计划（研究计划 / 工作计划）

**用途**：开题后的研究计划、学期工作计划、活动计划。

```
[单位/项目][时间段]工作（研究）计划

一、指导思想与总体目标（2-3句）
二、主要任务（分条，每条含：任务名、内容、责任人、完成标志）
三、进度安排（表格优先：时间节点 × 任务 × 里程碑/交付物）
四、保障措施（人员分工、条件资源、风险预案）
```

**要点**：任务可检查（有完成标志），时间节点具体到月；与申报书/任务书口径一致。
**常见错误**：目标与任务脱节；只有任务没有时间节点。

## 5. 实习总结

**用途**：专业实习/毕业实习总结报告。

```
[单位名称]实习总结
实习岗位、实习时间、校内/企业指导教师

一、实习单位与岗位概况（业务、组织、岗位职责）
二、实习内容与完成情况（按时间或按项目分述，突出与专业的结合点）
三、主要收获（专业知识应用、工程/实务能力、职业素养，各配实例）
四、存在问题与改进方向
五、对专业教学/培养方案的建议（可选）

实习生签名 / 日期
```

**要点**：收获必须配具体实例（做了什么→学到什么）；涉及企业内部信息按保密
要求脱敏。
**常见错误**：写成流水账（逐日记录）；收获部分只有形容词没有实例。

## 6. 就业材料（求职信 / 附信）

**用途**：求职信、推荐信底稿、实习申请附信。

```
尊敬的[招聘负责人姓名/职务]：

您好！我是[学校][专业][年级]学生[姓名]，从[渠道]获知贵单位招聘[岗位]。
（第一段：应聘岗位 + 一句话匹配度结论）

（第二段：能力匹配——用2-3个与岗位要求对应的事实：课程/项目/竞赛/实习，
每条含可量化结果）
（第三段：对单位/岗位的认识 + 能投入的时间与到岗信息）

此致
敬礼！

求职人：[姓名]
联系电话：[手机]  邮箱：[邮箱]
[日期]
```

**要点**：一页以内；每个论断配证据（成果、数据、作品链接）；称呼与落款格式规范。
**常见错误**：群发痕迹（未提具体单位/岗位）；把简历全文复述成段落。

## 7. 汇报材料（汇报提纲底稿）

**用途**：向导师/学院/评审的汇报发言稿、汇报 PPT 的文字底稿。

```
关于[事项]的汇报（提纲）

一、基本情况（一段话说清背景与现状）
二、主要工作与成效（3-5条，每条"做了什么→结果如何"，数据支撑）
三、存在问题（如实，1-2条）
四、下一步打算（与问题对应，含时间节点）
五、需要说明/请示的事项（如有：资源、政策、协调需求）
```

**要点**：口头汇报每条不超过 60 字；先结论后论据；需要请示的事项单独成节，
不与"下一步打算"混淆。
**常见错误**：成效与"主要工作"重复；请示事项埋在段落里不突出。

## 检查顺序建议

成稿后按上游安装目录的 `checklists/quality-checklist.md` 顺序检查：格式 → 内容 → 语言 → 逻辑 → 细节；
高校场景附加检查：目标-内容-成果闭环（申报/计划类）、数据可核对性（总结/汇报类）、
证据支撑度（就业/申请类）。
