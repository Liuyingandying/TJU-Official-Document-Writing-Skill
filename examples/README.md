# Examples

本目录收录使用示例与产出说明。

## 交互示例

| 输入 | 行为 |
|---|---|
| "帮我写一份科研项目阶段总结" | 命中总结文种，按阶段总结结构产出正文 |
| "帮我写一份 FPGA 比赛总结，只给正文" | 命中比赛总结模板（competition_summary），仅输出 Markdown 正文，不产生文件 |
| "帮我生成一份 FPGA 比赛总结 Word" | 内容写作 + 调用运行环境的文档生成能力产出 DOCX（需要环境提供该工具） |
| "总结一下这个模块做了什么" | 普通对话，不进入写作 Skill |
| "分析一下这份项目总结哪里写得不好" | 分析任务，不产出文档 |

## 结构对照（比赛总结模板 → 实际成文）

模板（references/competition_summary.md）定义的五节：

```
一、赛题与备赛概况
二、方案与实现
三、比赛过程复盘
四、成绩与不足
五、经验与建议
```

真实跑通记录（ZCode Runtime）：

- 文种判定：总结（竞赛项目总结）
- 排版产物：DOCX，document_type=总结，status=success，verify=13/13
- 无参考文献强制告警（总结类文种按策略跳过 GB/T 7714 检查）

## 表格题注示例（重要约定）

```markdown
表：系统关键指标测试结果

| 测试项 | 迁移前 | 迁移后 | 要求 | 结论 |
|---|---|---|---|---|
| 触觉刷新率 | 1.8 kHz | 10 kHz | ≥ 4 kHz | 达标 |
```

注意 `表：` 后接全角冒号、空一行再写表格——详见 README 的 Markdown Conventions。
