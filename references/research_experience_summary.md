# 科研经历总结模板（Research Experience Summary）

> TJU-Official-Document-Writing-Skill ｜ references 高校模板库 2/6
> 适用于：保研/考研复试材料、导师双选自述、奖学金申请附件。与"项目结题报告"的区别：面向陌生评审者，重"我做了什么、证明了我什么能力"，不重内部过程细节。

## 使用场景

- 复试/面试前提交的科研经历书面材料（1—2 页）；
- 套磁邮件附件（压缩至半页版）；
- 奖学金、优秀学生评审的科研板块素材库。

## 推荐结构

```
一段式总起（100 字）：参与项目总数、方向、本人角色定位（独立负责 X 项 / 核心成员 X 项）

经历一（最重要项目，250-350 字）
  项目名 + 周期 + 来源（大创/导师课题/自选）
  问题：要解决什么（一句话，外行能懂）
  本人职责：具体到模块/任务级
  方法与结果：关键技术路线 + 量化产出（论文/专利/演示/数据提升 %）
  能力证明：这段经历证明了我什么（方法论/工具/协作）

经历二、三（次要项目各 150-200 字，同样四要素压缩）

总结段（100 字）：能力图谱一句话 + 与下一步方向（读研方向）的衔接
```

## 禁止事项

- 禁止把团队成果写成个人成果；多人项目必须写明本人分工；
- 禁止只写"参与了 XX 项目"而无具体职责与产出；
- 禁止技术名词堆砌（把会用到的工具全部列出）——按"问题→方法→结果"取舍；
- 禁止出现未发表成果的过度承诺（"即将发表 SCI"）；写"在投/撰写中"并注明状态；
- 禁止负面评价队友或归因于他人。

## 示例（一段）

> 基于 STM32 与 FPGA 的智能触觉反馈系统（国家级大创，2025.03—2026.03，核心成员）：针对触觉渲染实时性不足的问题，我主导了从 STM32 原型到 Artix-7 FPGA 的架构迁移，完成采样、滤波与渲染三个 RTL 模块设计及 I2C 控制链路重构。迁移后触觉刷新率由 1.8 kHz 提升至 10 kHz，端到端时延由 2.3 ms 降至 0.4 ms，项目获省级竞赛二等奖。该经历证明了我具备硬件描述语言设计、时序收敛与系统集成验证的完整工程能力。
