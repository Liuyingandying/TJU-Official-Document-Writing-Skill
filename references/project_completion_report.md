# 项目结题报告模板（Project Closing Report）

> TJU-Official-Document-Writing-Skill ｜ references 高校模板库 5/6
> 与 tju-extension §2（阶段总结）的分工：阶段总结面向过程中期报送；**结题报告**面向验收评审，重"对照任务书的完成度闭环"。报送格式以主管部门模板为准时，本模板做内容组织、官方表格做载体。

## 使用场景

- 大创项目（国家级/市级/校级）结题验收；
- 校级科研基金项目、实验室开放课题结题；
- 竞赛类项目需向主办方报送的结题材料。

## 推荐结构

```
一、项目概况（200 字）
    项目名/编号/级别/周期/负责人/经费；立项目标两三句回顾
二、任务完成情况对照表（核心，必须为表）
    列：任务书条目 | 计划目标 | 完成情况 | 佐证材料
    逐条对照，完成/部分完成/调整三态，调整须注原因
三、主要成果（400-600 字）
    成果清单表：类型（论文/专利/软著/样机/报告）| 名称 | 状态 | 署名
    1-2 段代表性成果展开（问题→方法→结果→价值）
四、经费使用情况（表格）
    预算科目 | 预算数 | 决算数 | 执行率；大额调整说明
五、人才培养与能力建设（150-300 字）
    成员分工与成长；支撑的课程/毕设/后续研究
六、存在问题与展望（200 字）
    未尽事项如实说明；后续研究计划
```

## 禁止事项

- 禁止任务书条目漏对照——评审第一眼看的就是闭环表，调整项必须留痕（中期报告/变更申请）；
- 禁止成果注水：在投论文不得写"已发表"，未授权专利不得写"已授权"，署名与实际不符属学术不端；
- 禁止经费科目间随意串写而无审批依据；执行率为 0 的科目要有说明；
- 禁止"进展顺利、圆满完成"式空话替代事实表述；
- 禁止遗漏失败与调整——验收评审反而看重如实披露与归因。
