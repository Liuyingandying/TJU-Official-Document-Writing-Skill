# 保研个人陈述模板（Personal Statement）

> TJU-Official-Document-Writing-Skill ｜ references 高校模板库 1/6
> 语言规范沿用上游 `official-document-writing/references/writing-techniques.md`（准确、平实、简明、庄重）。

## 使用场景

推荐免试研究生（保研）申请材料；亦适用于夏令营/预推免报名系统的个人陈述栏。
篇幅约束：多数院校要求 1500—2000 字，一页半以内；系统填报时注意字数上限。

## 推荐结构

```
开头段（150 字）：身份一句话（学校/专业/排名）+ 报考方向 + 一句话匹配度结论
一、学业基础（300-400 字）
    核心课程与成绩、排名走势；用数据，不堆形容词
二、科研经历（500-600 字，全文重心）
    项目背景一句 → 本人具体职责 → 关键技术贡献（做什么、怎么做、结果）→ 收获
    每段一个项目，最多两个，宁可深不可泛
三、实践与竞赛（200-300 字）
    与报考方向相关的竞赛/实习/工程实践，各配一个量化结果
四、报考方向与研究设想（300-400 字）
    对目标方向的理解（读过文献/了解课题组工作）+ 入学后的学习与研究计划
结尾段（100 字）：态度与承诺，呼应开头
```

## 禁止事项

- 禁止通篇抒情、堆砌"热爱/执着/梦想"等空泛表述而不给事实；
- 禁止罗列与报考方向无关的经历（学生会文体活动一笔带过即可，或删除）；
- 禁止复制奖学金清单凑字数——获奖情况是简历/成绩单的事，陈述里只挑 1—2 项佐证能力；
- 禁止出现目标院校导师姓名的私人化表述（"慕名已久"），改为对其研究方向的事实性引用；
- 禁止夸大：竞赛"参与"不得写成"主导"，合作成果不得隐去合作者独揽。

## 示例（开头段）

> 我是天津大学光电信息科学与工程专业 2023 级本科生，专业排名 3/126（前 2.4%）。我希望报考贵院电子科学与技术学科太赫兹技术方向。过去两年里，我围绕太赫兹通信与感知完成了从文献调研、系统仿真到样机验证的完整训练，确认了以科研为业的职业目标。

（正文示例段落——科研经历）
> 在校级大创项目"面向 6G 的 THz-ISAC 关键技术研究"中，我负责波形仿真模块：将 OFDM 一体化波形的感知克拉美-罗下界分析实现为可复用的 Python 仿真框架，完成了 3 种信道模型下的对比实验，仿真结论被写入项目中期报告。这段经历使我掌握了从理论推导到数值验证的完整方法链，也让我确认了继续深造的必要性。
