# 实习总结模板（Internship Summary）

> TJU-Official-Document-Writing-Skill ｜ references 高校模板库 3/6
> 与 tju-extension `references/tju-academic-scenarios.md` §5（教学场景实习总结）互补：本模板面向**提交学校备案/学分认定**的正式版，增加了收获与专业的对应关系及保密脱敏要求。

## 使用场景

- 专业实习/毕业实习结束后向学院提交的总结报告（2000—3000 字）；
- 实习学分认定材料；用人单位评价表的自述栏（压缩版）。

## 推荐结构

```
一、实习单位与岗位概况（300 字）
    单位业务一句话 + 所在部门职责 + 本人岗位与汇报关系
二、实习内容与完成情况（800-1200 字，全文重心）
    按 2-4 个任务/项目分节，每节：
    任务目标 → 本人具体工作 → 使用的技术/工具 → 完成结果（量化）
    建议一张"任务-产出对照表"
三、专业知识与能力的对应与提升（400-600 字）
    至少三组"课程知识 → 实际应用"对应（如：信号与系统 → 传感器数据处理）
    补充课堂之外的新收获（工程流程/协作/行业认知）
四、问题与不足（200-300 字）
    实习中暴露的自身短板 + 原因 + 改进措施
五、总结与建议（200 字）
    对个人发展的意义；对专业教学的建议（可选）
```

## 禁止事项

- 禁止写成流水账（逐日/逐周记录工作内容而无提炼）；
- 禁止泄露实习单位商业秘密：内部数据、未公开产品信息、客户信息一律脱敏或删除；
- 禁止只有形容词没有实例（"收获很大、能力提升明显"必须配"做了什么→学到什么"）；
- 禁止抱怨性表述（加班多、带教差）；困难一律按"问题→应对"陈述；
- 禁止虚构未参与的项目——备案材料可能被抽查核实。

## 示例（"对应与提升"小节）

> 课程《信号与系统》中的滤波理论在实习中得到了直接应用：我负责的传感器数据去噪任务要求在 50 Hz 工频干扰下提取有效信号，我采用课程所学的带阻滤波级联低通方案，将信噪比提升约 12 dB。这让我认识到基础课程的实际价值，也暴露出我从"会推导"到"会选型调参"之间的差距——实习后期我系统补做了滤波器工程化设计的学习笔记。
